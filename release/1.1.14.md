# Day Wheel Quest Markers 1.1.14

## Changes

- Fixes missing and duplicate weekday reminders caused by the older separation between task-completion routing and one-time dialogue ownership.
- Generalizes the remaining answer-backed task routes through Graveyard Keeper's verified local FlowCanvas topology instead of maintaining route-specific mappings.
- Rebuilds one-time `@` dialogue ownership only after navigation is known, so follow-up choices inside an already-reminded visit are not counted as extra reminders while independently reachable interactions remain covered.
- Keeps only the two genuinely event-only stages as narrow verified fallbacks.
- Upgrades the persistent interaction cache to schema 7. Older cache files rebuild automatically during loading; no manual cache cleanup is required.
- Keeps FlowCanvas graph parsing out of normal gameplay.

## Verified

Tested on Graveyard Keeper 1.407:

- schema-7 bootstrap reached the canonical `Ready` state with no Day Wheel Quest Markers warning/error;
- the developed save showed the expected **3 weekday markers**;
- completing the Snake/Envy Better Save Soul interaction changed the wheel from **3 markers to 2**, removing only that consumed reminder;
- a subsequent launch loaded the persisted schema-7 manifest in **10.43 ms** with FlowCanvas graph parsing skipped.

Install by replacing the previous `DayWheelQuestMarkers.dll` in `BepInEx/plugins/`.

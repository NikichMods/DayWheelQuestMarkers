# Day Wheel Quest Markers 1.1.15

- Removes the calendar reminder for the Merchant's optional loan offer.
- Keeps reminders for repaying an existing debt and all other conversations unchanged.
- Existing interaction caches continue to work without manual cleanup.

Tested on Graveyard Keeper 1.407: the Merchant marker disappears when only the loan offer is available, while the offer itself remains in the dialogue.

Install by replacing `DayWheelQuestMarkers.dll` in `BepInEx/plugins/`.

# Day Wheel Quest Markers 1.1.9

## Changes

- Fixes missing weekday reminders for Better Save Soul interactions that require multiple simultaneous dialogue requirements.
- Adds generic support for the game's relay-backed compound AnswerData structure instead of special-casing individual NPCs or quest items.
- Uses Graveyard Keeper's native AND semantics for compound requirements: every required child gate must be satisfied before the marker appears.
- Upgrades the persistent interaction cache to schema 6. Existing older cache files rebuild automatically during loading; no manual cache cleanup is required.
- Keeps FlowCanvas graph parsing out of normal gameplay.

## Verified

Tested on Graveyard Keeper 1.407:

- the previously missing Snake/Envy Better Save Soul reminder appeared alongside two existing reminders;
- after completing the Snake interaction, the wheel changed from **3 markers to 2**, removing only the consumed reminder;
- persisted schema-6 reload completed with FlowCanvas parsing skipped.

Install by replacing the previous `DayWheelQuestMarkers.dll` in `BepInEx/plugins/`.
